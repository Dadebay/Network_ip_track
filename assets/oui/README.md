# OUI verisi

`oui.csv` dosyası IEEE MA-L kayıt listesidir:
https://standards-oui.ieee.org/oui/oui.csv

Uygulama bu dosyayı `IeeeOuiDatabase` ile yükler. Dosya yoksa cihaz
üreticileri "Bilinmiyor" olarak kalır; herhangi bir tahmin yapılmaz.

Güncellemek için dosyayı yeniden indirip bu klasöre koyun.
